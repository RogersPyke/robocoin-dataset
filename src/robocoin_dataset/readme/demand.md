# 数据集元信息字段规范
本文档定义了 RoboCOIN 数据集各 JSON 文件的字段规范，包含字段名称、数据类型、描述、必填要求、枚举值/标准模板、数据来源/备注等核心信息。

## 1. 环境信息 (scene_info.json)
| 信息类别 | 名称         | 字段名            | 数据类型 | 描述                                                                 | 要求 | 枚举/标准模板/备注                          | Robodriver参数 |
|----------|--------------|-------------------|----------|----------------------------------------------------------------------|------|---------------------------------------------|----------------|
| 环境信息 | 环境类型     | env_type          | string   | 环境类型                                                             | 必选 | real world、simulation                      | Y              |
| 环境信息 | 场景类型     | scene_type        | string   | 工业生产、生活服务、零售电商等（附件1-场景分类表）<br>标准模板：家庭场景-卧室 | 必选 | 场景树                                      | Y              |
| 环境信息 | 物体清单     | object_list       | string   | 都包括哪些物体道具（附件2-物体分类表）<br>标准模板：一级分类-二级分类+材质+颜色 | 必选 | 物品树                                      | -              |
| 环境信息 | 地面材质     | surface_material  | string   | 地面材质，如水泥、木板、瓷砖、草地等                                 | 可选 | -                                           | -              |
| 环境信息 | 光源信息     | light             | string   | 光照强度、色温属性、无影灯                                           | 可选 | -                                           | -              |
| 环境信息 | 噪声水平     | noise_level       | string   | 环境的噪声水平，单位为分贝（dB）                                     | 可选 | -                                           | N              |

## 2. 任务描述 (task_info.json)
| 信息类别 | 名称         | 字段名               | 数据类型 | 描述                                                                 | 要求 | 枚举/标准模板/备注                          | Robodriver参数 |
|----------|--------------|----------------------|----------|----------------------------------------------------------------------|------|---------------------------------------------|----------------|
| 任务描述 | 任务操作类型 | task_operation_type  | string   | 固定单臂操作、固定双臂操作、移动单臂操作、移动双臂操作、人机协作       | 必选 | 任务操作类型                                | N              |
| 任务描述 | 任务结果     | task_result          | string   | 任务执行结果                                                         | 必选 | 成功、失败，标准值："success","failure"     | 子任务标注产生 |
| 任务描述 | 任务名称     | task_name            | string   | 任务名称                                                             | 必选 | 标准模板：{Robot_name}+{composite action}+{Object} | 拿的到但不符合标准 |
| 任务描述 | 任务指令     | task_instruction     | string   | 所执行任务的自然语言描述，比如：叠衣服                               | 必选 | 标准模板：{composite action}+{Object}       | 拿的到但不符合标准 |
| 任务描述 | 操作步骤     | task_description     | string   | 任务操作步骤                                                         | 必选 | 标准模板：{Left_arm, Right_arm}+{atomic skill}+{Object}； | 子任务标注产生 |
| 任务描述 | 技能清单     | skill_list           | string   | 涉及的原子技能序列（附件3-标准原子技能表）                           | 必选 | 原子技能                                    | Y              |
| 任务描述 | 模态清单     | sensor_list          | string   | 确定所需模态，如视觉：RGB 图像、深度图；力触觉：末端执行器力数据、扭矩数据；运动：关节位置 / 速度数据；语音：任务指令语音 | 必选 | info.json自带                               | Y              |

## 3. 本体信息 (body_info.json)
| 信息类别 | 名称         | 字段名               | 数据类型 | 描述                                                                 | 要求 | 枚举/标准模板/备注                          | Robodriver参数 |
|----------|--------------|----------------------|----------|----------------------------------------------------------------------|------|---------------------------------------------|----------------|
| 本体信息 | 机器人名称   | robot_name           | string   | 机器人型号名称，比如：Leju_Kuavo4pro。                               | 必选 | 标准模板：{Manifacurer}+{Robot model}       | 拿的到但不符合标准 |
| 本体信息 | 末端工具类型 | endeffector_name     | string   | 末端工具型号名称，比如：Inspire_RH56BFX。                             | 必选 | 规范字符串：<br>two_finger_end_effector<br>three_finger_end_effector<br>five_finger_end_effector | Y              |
| 本体信息 | 遥操方式     | tele_type            | string   | 遥操作方式                                                           | 必选 | 同构臂、VR手柄、人体动捕等                   | 遥操作方式     | Y              |
| 本体信息 | 摄像头       | came_info            | string   | 型号、内参、外参、采集频率                                           | 必选 | 外来数据拿不到                               | -              |
| 本体信息 | 触觉传感器   | tactile_info         | string   | 厂商、型号、感知方式等                                               | 可选 | -                                           | -              |
| 本体信息 | 声音传感器   | sound_info           | string   | 厂商、型号、感知方式等                                               | 可选 | 默认右手系                                  | Y              |

## 4. 坐标信息 (coordinate.json)
| 信息类别 | 名称         | 字段名               | 数据类型 | 描述                                                                 | 要求 | 枚举/标准模板/备注                          | Robodriver参数 |
|----------|--------------|----------------------|----------|----------------------------------------------------------------------|------|---------------------------------------------|----------------|
| 坐标信息 | 坐标系定义   | coordinate_definition| string   | 选择的坐标系定义方式，RoboCOIN中统一为标准坐标系（x前/y左/z上的右手坐标系）。 | 必选 | -                                           | N              |
| 坐标信息 | 基坐标零位   | origin_xyz           | float    | 基座坐标系在世界坐标系中的原点位置及姿态                             | 必选 | -                                           | -              |
| 坐标信息 | 本体变换矩阵 | base_transform       | float    | 本体坐标系相对于基坐标系的空间变换关系                               | 可选 | -                                           | -              |
| 坐标信息 | 末端变换矩阵 | end_transform        | float    | 末端执行器坐标系相对于基坐标系的空间变换关系                         | 可选 | 定义features                                | Y              |

## 5. 量纲信息 (dimension.json)
| 信息类别 | 名称             | 字段名               | 数据类型 | 描述                                                                 | 要求 | 枚举/标准模板/备注                          | Robodriver参数 |
|----------|------------------|----------------------|----------|----------------------------------------------------------------------|------|---------------------------------------------|----------------|
| 量纲信息 | 关节转动量纲定义 | joint_rotation_dim   | string   | 关节转动的量纲                                                       | 必选 | Angle or radian                             | 数据转换标准/定义features |
| 量纲信息 | 末端转动量纲定义 | end_robtation_dim    | string   | 末端转动的量纲                                                       | 必选 | Angle or radian                             | info.json自带/定义features |
| 量纲信息 | 末端移动量纲定义 | end_translation_dim  | string   | 末端移动的量纲                                                       | 必选 | M or mm                                     | info.json自带/定义features |
| 量纲信息 | 底盘转动量纲定义 | base_robtation_dim   | string   | 底盘转动的量纲                                                       | 必选 | Angle or radian                             | info.json自带/定义features |
| 量纲信息 | 底盘移动量纲定义 | base_translation_dim | string   | 底盘移动的量纲                                                       | 必选 | M or mm                                     | info.json自带 |

## 6. 数据标注 (label_info.json)
| 信息类别 | 名称         | 字段名               | 数据类型 | 描述                                                                 | 要求 | 枚举/标准模板/备注                          | Robodriver参数 |
|----------|--------------|----------------------|----------|----------------------------------------------------------------------|------|---------------------------------------------|----------------|
| 数据标注 | 轨迹层       | Trajectory-level_label | string   | 描述整体场景、物体属性                                               | 可选 | -                                           | -              |
| 数据标注 | 片断层       | Segment-level_label  | string   | 子任务描述和时间戳标注                                               | 必选 | 场景标注产生                                 | -              |
| 数据标注 | 帧层         | Frame-level_label    | string   | 逐帧标注末端执行器运动状态（速度、加速度、夹爪开合）                 | 可选 | -                                           | N              |

## 7. 操作信息 (operation_info.json)
| 信息类别 | 名称         | 字段名               | 数据类型 | 描述                                                                 | 要求 | 枚举/标准模板/备注                          | Robodriver参数 |
|----------|--------------|----------------------|----------|----------------------------------------------------------------------|------|---------------------------------------------|----------------|

| 操作信息 | 修改人员     | data_modifier        | string   | 修改人员姓名                                                         | 可选 | -                                           | -              |
| 操作信息 | 修改日志     | modify_logo          | string   | 记录数据集修改信息                                                   | 可选 | 增加数据说明文档                             | -              |
